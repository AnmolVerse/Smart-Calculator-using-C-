# Smart Calculator – C++ Console Calculator

# Description
Smart Calculator is a C++ console-based calculator supporting:  
- Basic arithmetic: Addition, Subtraction, Multiplication, Division, Modulus  
- Powers, Square, Cube  
- Square Root (supports complex numbers for negative inputs)  
- Cube Root, Factorial  
- History Tracking: View or clear previous calculations  

It features an interactive menu, history logging in History.txt, and works with integers and floating-point numbers. Perfect for practicing C++ skills and demonstrating programming proficiency.

# Features
- User-friendly console interface  
- Calculation history saved automatically  
- Handles negative numbers in square roots using *complex number output*  
- Supports continuous calculations with a *main menu*  

# How to Use
1. Run SmartCalculator.cpp in a C++ compiler.  
2. Select an operation from the menu.  
3. Enter numbers as prompted.  
4. View results and optionally save them in history.  
5. Access history anytime, and choose to clear it if needed.
